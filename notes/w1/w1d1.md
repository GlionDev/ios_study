## let / var
let 은 변경 불가능한 변수(상수)를 선언할때 사용(Kotlin 의 val 과 비슷함)
```
let name = "Glion"
```
Kotlin 과의 차이점은, Kotlin 은 val 로 저장된 객체의 내부 필드는 변경 가능하지만, Swift 의 let 으로 저장된 struct 의 내부 필드도 바꿀 수 없다는 점.
```kotlin
class Person(var name: String)

val person = Person("홍길동")
person.name = "김철수" // 가능 - swift 에서는 이러한 형태도 불가능. 
// 구조체는 아직 배우지 않았기에 이런 형태가 불가능하다는 것을 이해하고, 코드 예시는 붙이지 않는다.
person = Person("김철수") // 불가능
```

## Swift 의 특징
- 타입을 붙이지 않아도 알아서 지정된다.(kotlin 과 동일)
  - 단, Float 형은 지정해주어야 한다. 지정되지 않은 소수점은 Double 형이다.
- 숫자 타입 간 암묵적 변환을 지원하지 않는다. 명시적으로 변환해주어야 한다.
  ```swift
  let a = 1
  let b = 1.5
  let mul = a * b // 불가능
  let mul = Double(a) * b // 가능
  ```
- 문자열 보간은 \() 를 사용한다
  ```
  let name = "홍길동"
  print("이름은 \(name) 입니다.")
  ```
- Swift 의 `Int` 타입은 Kotlin 의 `Long` 타입이다.(64비트라서) 보통 `Int` 를 주로 쓰지만, Kotlin 의 `Int` 와 같은 형태를 쓰고 싶다면, Swift 에서는 `Int32` 로 사용한다.

## Optional
- Kotlin 에서 Nullable 한 값을, Swift 에서는 Optional 한 값, Optional 타입이라고 한다.
- 그냥 출력 시 `Optional(Wrapped)` 가 출력된다.
- 내부 형태는 enum 으로
  ```swift
  enum Optional<Wrapped>
  case none // nil
  case some(Wrapped) // 값 존재
  ```
  이런 형태이다.
- Swift 에서 nil 은, Kotlin 의 null 과 비슷하지만, 실제로는 Optional 타입의 none 을 의미한다.
- Optional 관련 연산자
  - 선언 : let a: String`?` = nil
  - nil 기본값 처리 : a `??` "Default"
  - 체이닝 : a`?.`
  - 강제 언래핑 : a`!` (이 경우, 실제로 a 가 nil 이라면 크래시 발생한다.)

- Kotlin 과 달리 스마트 캐스트가 없다. Kotlin 은 값이 null 이 아님을 확인헀다면 사용 가능하지만, Swift 는 그렇지 않다.  
  따라서 **아래의 `if let` 이나 `guard let` 이 필요하다.
  ```kotlin
  val name: String? = "홍길동"
  if(name != null) {
    print("$name") // 가능
  }
  ```
  ```swift
  let name: String? = "홍길동"
  if name != nil {
    print("\(name)") // Optionl(name) 이 출력된다.
  }
  ```

## Optional 안전하게 꺼내기 - if let
if + let 의 형태
`if let` 은 조건에 맞을때만 값을 사용한다.
, 를 사용하여 AND 조건으로 여러 조건을 붙일 수 있다. 마치 Kotlin 의 `(a != null && b != null)` 과 같이 사용 가능하다.
```swift
let name: String? = nil
let age: Int? = nil

// 옛날 스타일
if let unwrapped = name {
    // {} 블럭 안에서만 unwrapped 된 값 사용이 가능하다
    print("\(unwrapped) 값이 있습니다.")
} else {
    // 여기서는 여전히 Optional<Wrapped> 형태이다. 출력을 하면 Optional 형태로 나온다.
    print("이름 값이 없습니다.")
}

// 요즘 스타일
if let name {
    print("\(name) 값이 있습니다.")
} else {
    print("이름 값이 없습니다")
}

// 여러 조건.
if let name, let age, age >= 30 {
    // name 과 age 가 모두 값이 있고(nil 이 아님) 30 이상일때
    print("\(name) 의 나이는 \(age) 입니다.")
} else {
    // name 이나 age 둘 중 하나가 nil 이거나, 둘다 nil 이거나, age 가 30 미만이거나 등 여러 조건이 존재한다.
    // 내부에서 필요한 만큼 다시 조건을 달아야 한다.
}
```
**if let 은 값이 있을때만 수행해야 하는 경우(값이 있을때만 스낵바 메시지 뿌리기 등)** 에 사용된다.

## Optional 안전하게 꺼내기 - guard let
guard + let 의 형태.
`guard` 는 **값을 사용하기 전 조건을 먼저 확인하고, 조건에 맞지 않으면 return 시킴**
이떄 컴파일러에 의해 빠져나가는 것이 강제된다. `return` 이나 `throw`, `break`, `continue` 등 모두 가능하지만, 중요한것은 빠져나가는 것이다.

- Optional 체크
  ```swift
  let name: String? = nil
  
  guard let name else {
      // name 이 nil 일 경우, 이 블럭이 실행되고 return 된다
      print("이름값이 없습니다.")
      return
  }
  ```
- 조건 체크
  ```swift
  let age = 30
  guard age >= 30 else {
    print("나이가 30살 미만입니다.")
    return
  }
  ```
guard 로 꺼낸 값은 블럭 아래에서 계속 사용 가능하다. guard 에 의해 조건이 걸러지고 안전한 값임을 return 에 의해 보장받았기 때문이다.
**guard 를 쓸 때는 조건에 맞지 않으면 아래 코드가 실행되지 않아야 할때** 사용된다.
