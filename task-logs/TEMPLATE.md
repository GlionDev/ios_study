# 작업 기록 템플릿

> 사내 iOS 작업 1건마다 이 파일을 복사해서 기록한다. 이력서 문장과 면접 답변의 재료로 쓴다.

## 사용법

```bash
# 작업 번호와 짧은 영문 설명으로 파일명을 정한다
cp task-logs/TEMPLATE.md task-logs/01-memory-leak-search-vc.md
```

- 작업을 시작할 때 1~2번을 쓰고, 끝낸 당일에 3~7번을 쓴다.
- 2번(원인 분석)과 3번의 "왜 이 방법인가"를 가장 자세히 쓴다. 면접관이 깊게 묻는 부분이다.
- 이 폴더는 사내 코드가 들어가므로 외부에 공개하지 않는다. 블로그나 포트폴리오로 옮길 때는 클래스명과 도메인 용어를 일반화하고 코드는 새로 써서 올린다.
- 아래 `---` 이후 부분만 남기고, 사용법 섹션은 지운다.
